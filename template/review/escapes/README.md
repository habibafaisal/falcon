# Escapes

An **escape** is a miss a human caught that every automated layer let through. Each one is recorded as
`ESC-YYYY-NNN.md` (template: `.claude/skills/review-harness/templates/escape.md`) and is incomplete
until it ships a **new check** in the same session — a scenario, hazard row, principle, test, or hook.

Notes are not enforcement. An escape that only produces prose will recur.
